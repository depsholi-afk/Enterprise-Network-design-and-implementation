# Enterprise Network Design and Troubleshooting

## Network Design
- Designed a redundant, collapsed-core enterprise network using multiple VLANs, SVIs, VLSM, inter-VLAN routing, a DNS server, and a DHCP server.

## Routing and Redundancy
- Implemented HSRP with per-VLAN load balancing, EtherChannel, LACP, STP, OSPF dynamic routing, static routes, next-hop default routes, and NAT/PAT translations.

## Security and Remote Access
- Implemented ACLs, port security, SSH, and device security to control network access and support remote management.
